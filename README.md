Git Flow Lab – Dark Mode Toggle

A simple webpage with a dark mode toggle button using HTML, CSS, and JavaScript.

Features
Switch between Light Mode and Dark Mode.
Button updates text dynamically: 🌙 Dark Mode / 🌞 Light Mode.
Dark theme affects body, header, navigation links, and buttons.
Usage
Open index.html in a browser.
Click the Dark Mode button to toggle themes.
How It Works
JavaScript toggles data-theme="dark" on the body.
CSS applies dark styles when [data-theme='dark'] is present.
Button text changes according to the active theme.
